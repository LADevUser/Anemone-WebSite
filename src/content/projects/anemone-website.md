Webbplatsen är den första gemensamma ytan för Anemone. Den byggs statiskt med Astro och publiceras via GitHub Pages.

Den nuvarande fasen fokuserar på struktur, läsbarhet och ett enkelt arbetssätt för innehåll. Nya funktioner läggs bara till när det finns ett tydligt behov.

Allt innehåll ligger tillsammans med koden och kan granskas genom vanliga Git-flöden.
